## 3. 结论：功能缺口与补入

**必须补（本次 PRD 更新）**
1. **网页浏览导入（F-32，P0）**：Zotero/SciSpace 均以"浏览器一键抓取"为入口核心；我们 v1 不做插件，改为**站内内嵌网页浏览面板**——在平台内浏览 arXiv / Semantic Scholar / ACL Anthology / OpenReview 的检索结果，勾选即导入，等效替代插件体验
2. **引用导出 BibTeX/GB/T 7714（F-33，P1）**：文献管理工具标配，团队写论文/调研报告必需（复用 arXiv skill 的 BibTeX 生成逻辑）

**观察（P2 备选）**
- 多篇对比分析（SciSpace 特色）→ F-34
- 引文图谱（Connected Papers 特色）→ F-35
- 浏览器插件（Zotero 核心体验）→ v2 再议，先以内嵌浏览覆盖 80% 场景

## 4. 差异化护城河（更新版）

1. 团队阅读看板（技术负责人视角）
2. Obsidian 笔记导出（对接既有知识库）
3. 扫描版 PDF 支持（复用 PaddleOCR 容器）
4. 私有化部署（数据不出内网）
5. **内嵌网页浏览导入**（不装插件，一站完成 找→读→管→沉淀）
