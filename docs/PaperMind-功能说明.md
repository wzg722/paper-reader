## 1. 平台总览

### 1.1 定位
为 OCR / 考试防作弊研发团队提供**私有化论文精读平台**：AI 辅助 10 分钟读懂一篇英文论文，笔记自动沉淀知识库，团队共读共享。

### 1.2 页面结构（顶部导航 5 Tab + 个人中心）

| 页面 | 文件 | 内容 |
|---|---|---|
| 发现 | `index.html` | 搜索（热门词）、推荐卡片（分页）、本周热榜、导入入口 |
| 文献库 | `library.html` | 四 Tab：📚 我的文献 / ⭐ 收藏网站 / 📖 阅读器 / 📥 导入文献 |
| 图谱 | `graph.html` | Canvas 力导向知识图谱 |
| 知识库 | `vault.html` | 知识卡片/术语库/笔记聚合/导出 Obsidian |
| 社区交流 | `community.html` | 💬 动态 / 👥 团队 / 📤 分享 三页签 |
| 个人中心 | `profile.html` | 资料/统计/最近阅读/笔记/收藏/已加入团队/偏好设置/数据备份 |

浏览器标签页统一显示「PaperMind」。

## 2. 模块 1：用户体系与个人中心

### 2.1 注册 / 登录
- 注册：用户名 + 邮箱 + 密码；**新用户自动预置 6 个默认收藏网站**

| 区块 | 内容 |

| 统计 | 已读论文/笔记/高亮/精读时长/AI 提问数 |
| 最近阅读 | 进度条 + 继续阅读（直达阅读器对应位置） |
| 我的笔记 | 按论文聚合，📖 阅读直达笔记段落 |
| 我的收藏 | 收藏论文列表 |

## 3. 模块 2：文献库

### 3.1 我的文献
- **类别树**（左侧）：全部 / 按类别 / ⭐收藏 / **🗑 回收站**，计数实时
- **筛选**：状态（想读/在读/读完）、年份、标签；关键词搜索（`?q=`）
- **排序**：默认按最近阅读；星级收藏 ⭐、类别调整 📁、**移入回收站 🗑**
- **分页**：10 条/页（页码折叠 + 每页条数切换）
- **论文卡**：标题/一句话简介标签/作者/状态徽章/进度条 + 继续阅读、详情
- **详情面板**：状态/类别/标题中英/简介（可编辑+AI 生成）/作者/引用/标签/AI 总结/摘要 + 阅读原文、📤 分享、👥 共享（正式版）、简介编辑

### 3.2 导入文献（📥 Tab）
- **本地文件上传**：单个/批量（多文件多资料卡），演示支持 pdf/word/ppt/txt
- **资料卡**：类别/状态/标签（点击多选+自定义）/简介 + 🤖 AI 生成简介
- 单篇导入 / ✅ 批量导入全部 / 清空

### 3.3 阅读进度
- 阅读进度 % 随阅读记录，个人中心与文献库同步显示，继续阅读直达

## 4. 模块 3：阅读器

### 4.1 阅读模式
中英对照（默认）/ 原文 / 全译文 三模式切换；左右双栏段落联动高亮。

### 4.2 章节大纲跳转
左侧大纲：点击章节 → **正文滚动到对应章节**（对照/译文/原文模式均生效；PDF/Word/PPT 文件视图下自动切回文本模式再跳转），大纲高亮同步。

### 4.3 划词能力（选中文本自动弹出）
| 功能 | 说明 |
|---|---|
| 🌐 **AI 翻译 + ✨ AI 总结** | 选中文本**自动弹出**翻译+总结气泡（可**人工修改**，聚焦可编辑） |
| 📝 存为笔记 | 保存修改后的翻译+总结+选中文本（可见性三档：🌍公开/👥仅好友/🔒私密，默认公开） |
| ✨ 重新生成 | 丢弃人工修改恢复 AI 内容 |
| 🖍 高亮 | 5 色高亮 |
| 🤖 问 AI | 论文上下文问答（演示文案，正式版接大模型） |

### 4.4 截图 OCR（📷）
1. 截图模式（遮罩+十字光标，Esc 取消）→ 拖拽框选
2. 结果面板：截图预览 + 区域尺寸 + **OCR 识别结果（可编辑）** + **AI 翻译（可编辑）** + **AI 总结（可编辑）** + 存为笔记（保存修改版）
- 标注：正式版接 PaddleOCR 容器 + 大模型

### 4.5 多格式文件阅读（📄 格式切换）
| 格式 | 体验 |
|---|---|
| 论文文本 | 默认双语段落 |
| PDF | 分页白纸 + 页眉标题/作者 + 翻页 |
| Word | A4 文档流 |
| PPT | 16:9 幻灯片 + **缩略图导航**（点击跳页） |
| 通用 | 翻页 ‹ ›、缩放 −/＋（60-160%）、页数指示 |
- 标注「原型演示 · 正式版接入 PDF.js / Office Online」

### 4.6 其他
- 阅读器工具栏：📄格式/📷截图OCR/🌐语言/🔤A/A−/大纲
- 右侧 AI 对话面板

## 5. 模块 4：收藏网站与论文检索

### 5.1 收藏网站（⭐ Tab）
- **用户级收藏网站**（新用户自动预置 6 个默认），可添加/删除自定义网站
- 每个网站：名称/图标/描述 + 搜索框 → 检索结果列表（勾选/单篇/批量导入）
- **arXiv 来源 = 真实检索**（官方 API 免费无需 Key）：
  - 降级链：直连 arXiv → **本地代理 `arxiv_proxy.py`**（解决 CORS，`python arxiv_proxy.py`）→ 演示数据
  - 结果：真实标题/作者/年份/PDF 链接，可一键导入文献库
- 其余网站来源：演示数据 + 检索适配器说明（正式版接各自 API）

### 5.2 结果操作
勾选批量导入（选类别/状态/标签/简介+AI 生成）或单篇「导入」，已导入标记 ✓。

## 6. 模块 5：知识图谱

- **力导向图**（Canvas）：论文节点（方形，尺寸∝引用）+ 概念节点（圆形），有向边（引用方向/关联/属于）
- **交互**：拖拽节点/空白、缩放、重排、自动布局；节点点击 → 侧栏详情（论文=简介/AI总结/引用；概念=定义/标签）
- **知识点搜索** → 论文推荐：概念/标签命中、直接/间接关联、排序、一键**图谱定位/阅读/导入**
- 过滤（论文/概念）、中心论文 BFS 展开（3 层）
- 20+ 节点演示数据（papers + concepts + related）

## 8. 模块 7：社区交流（顶部第 5 Tab）

### 8.1 💬 动态流
- **全平台公开笔记 + 论文总结**按时间流展示（头像/昵称/角色/时间/论文卡片/内容/总结徽章）
- 我的公开笔记自动进入动态流；私密笔记任何人不可见
- **筛选下拉框**：全部（默认）/ 论文总结 / 笔记 / 我的 + 关键词搜索
- **分页**：5 条/页
- 互动：❤️ 点赞（计数）、💬 楼层评论（预置演示数据可互动）

### 8.2 论文社区聚合页
- 点动态论文卡片进入：论文信息 + 「去精读/详情」+ 该论文下**所有人的公开讨论** + 我的全部笔记（带可见性徽章 🌍/👥/🔒）

### 8.3 笔记可见性
- 三档：🌍 公开（社区可见）/ 👥 仅好友 / 🔒 私密（仅自己）
- 默认公开；保存后社区即时可见

## 12. 模块 11：数据安全（回收站/备份）

### 12.1 回收站
- 我的文献论文卡 🗑 → 确认移入回收站（左侧「🗑 回收站」项，计数实时）
- 回收站列表（划线标题 + 删除时间）→ **↩ 恢复** / **🗑 彻底删除**
- 删除后全站（发现/知识库/个人中心）同步隐藏

### 12.2 数据备份（个人中心）
- **⬇ 导出备份 JSON**：全部数据（论文/笔记/高亮/术语/收藏网站/图谱/分享/团队/设置）
- **⬆ 导入恢复**：校验 → 写入 → 刷新；换浏览器/电脑可迁移

## 13. 全局约定

| 项 | 约定 |
|---|---|
| 数据存储 | 原型：localStorage（pm_ 前缀）；正式版：MySQL（见数据库文档） |
| 分页 | 统一组件：页码折叠 + 5/10/20/50 切换 |
| 缓存 | 资源带 `?v=` 版本号，改动后递增防旧缓存 |
| 演示边界 | AI 翻译/总结/OCR 为演示文案（正式版接引擎）；arXiv 检索可真实运行（代理脚本） |
| i18n | 中英双语文案，`data-i18n` 属性 + PM.t() |
