## 1. 目标

为 OCR / 考试防作弊研发团队提供**私有化论文精读平台**：10 分钟理解一篇英文论文（AI 总结 + 双语对照 + 划词问答 + 截图 OCR），笔记自动沉淀进 Obsidian 知识库，社区共享、团队协作，技术负责人可掌握团队阅读进展。

## 2. 范围

**做**：
- 用户体系（内部账号、角色权限、研究方向）
- 文献库：导入（本地文件/DOI/arXiv 检索）、回收站、文件夹、标签、筛选排序、阅读进度
- 双语阅读器：原文/对照/译文三模式、划词翻译/总结（可编辑）、5 色高亮、笔记（三档可见性）、章节大纲跳转、截图 OCR、多格式文件阅读（PDF/Word/PPT）
- AI 能力：六段式精读总结、术语表、中英摘要、论文问答、段落级全文翻译（缓存）
- 收藏网站：用户级预置 6 个、自定义、arXiv 真实检索导入
- 知识图谱：论文/概念节点、引用关系、知识点搜索推荐
- 知识库：AI 知识卡片、跨论文术语库、笔记聚合、统计卡跳转、Obsidian 导出
- 社区交流：公开笔记动态流、论文社区聚合、点赞评论、分页、下拉筛选
- 团队：创建/申请/审批/成员管理、已加入团队（个人中心）
- 论文分享：分享给个人/好友/团队、分享管理（收下/撤销）
- 个人中心 + 数据备份（导出/导入 JSON）
- 偏好设置：翻译/OCR 引擎配置 + 测试连接真实探测

**不做**（明确边界）：
- PDF 原生渲染与画布标注（原型模拟渲染；正式版接 PDF.js/Office Online）
- 公开注册、支付/会员体系（内部工具）
- 浏览器插件、移动端 App
- 实时消息通知（被点赞/被审批的推送，后续版本）
- 文献 PDF 批量爬取（仅存用户主动导入的文件，尊重版权）

## 5. 非功能需求

| ID | 需求 | 说明 |
|---|---|---|
| NFR-1 | 性能 | 列表/分页操作 ≤500ms；AI 翻译单段 ≤5s；搜索 ≤1s（原型本地数据即时响应） |
| NFR-2 | 兼容 | 现代浏览器（Chrome/Edge）；中文/English 全站切换（i18n 完整覆盖） |
| NFR-3 | 数据安全 | 数据本地持久化（原型 localStorage）；正式版 MySQL + 软删除 + 全量备份 JSON |
| NFR-4 | 隐私 | 笔记三档可见性严格执行：私密内容不出现在社区任何位置；分享不携带私密笔记 |
| NFR-5 | 可维护 | 原型资源带版本号（?v=）防缓存；结构验证脚本全站通过（HTML 标签闭合 + JS 语法） |
| NFR-6 | 演示边界 | AI 生成内容（翻译/总结/OCR）标注演示文案；arXiv 检索真实可用（代理脚本） |

## 6. 验收方式

1. **原型走查**：docs/prototype/ 直接浏览器打开，逐功能验收（验收标准见上表）
2. **CDP 自动化**：无头浏览器实测关键链路（社区动态/团队审批/分享链路/回收站/笔记定位/arXiv 检索），本版本已全部实测通过
3. **文档对齐**：需求（本文档）→ 功能说明（PaperMind-功能说明.md）→ 数据库（PaperMind-数据库设计文档.docx V2.0）三方一致
