# 00 — 项目章程：PaperMind 研读

> 阶段 0/1 交付物（已合并执行） | 版本 v2.0（全功能定稿） | 日期 2026-08-16

## 一句话目标
为 OCR / 考试防作弊方向的研发团队搭建**私有化论文精读平台**：AI 双语翻译 + 中心思想总结 + 划词问答 + 截图 OCR + 多格式阅读，让团队成员 10 分钟读懂一篇英文论文，笔记沉淀进知识库与 Obsidian，**社区共享、团队协作**（公开笔记动态流、团队创建/申请/审批、论文分享）。

## 干系人
- **使用者**：团队研究员（刘华成、张德勋等），技术负责人（查看团队阅读进展）
- **决策人**：技术负责人（王工）
- **AI 引擎**：公司 GPU 服务器（10.1.7.68 / 10.1.7.66，已有容器化经验）

## 技术约束（用户既定偏好）
- 后端 **Django + DRF**，前端 **Vue3**，数据库 **MySQL**，部署 **Nginx 高并发**
- 团队已有经验：Django 全栈（Annota 标注平台）、PaddleOCR/PP-Structure 容器部署、远程 GPU 服务器操作规范
- 笔记出口对接 **Obsidian 知识库**（vault 已存在）

## 风险初判
1. AI 翻译/总结依赖大模型服务——需决策自建（GPU 服务器）还是外部 API
2. 全文翻译 token 成本与耗时——必须段落级缓存 + 异步任务
3. 引用数/元数据外部接口限速——需要缓存与降级（arXiv 检索已验证：浏览器 CORS 受限，需后端/本地代理）
4. 扫描版 PDF 需 OCR 服务——可复用 PaddleOCR 容器（原型已实现截图 OCR 交互）

## 范围边界（一句话）
**做**：文献库（含回收站/备份）+ 收藏网站（arXiv 真实检索）+ 双语阅读器（划词翻译总结可编辑/截图 OCR/多格式/大纲跳转）+ AI 总结/问答 + 知识图谱 + 知识库（卡片/术语/笔记/Obsidian 导出）+ 社区交流 + 团队 + 论文分享 + 个人中心/偏好设置的内部 Web 平台；
**不做**：公开注册、支付会员、浏览器插件、移动端、PDF 原生标注渲染（原型模拟，正式版接 PDF.js/Office Online）、实时消息通知（后续版本）。
