# PaperMind 研读 — 论文阅读网站原型

仿 ReadPaper 的一站式英文论文精读平台：**AI 双语翻译 + 中心思想总结 + 划词高亮笔记 + 论文问答**。
本目录为可交互 HTML 原型（双击即开，零构建、无后端），用于开发前确认交互与页面。

> 竞品核验说明：原型功能结构参考 ReadPaper（研读）的公开功能形态——文献库管理、双语阅读器、
> AI 总结、论文问答、划词翻译/高亮/笔记、阅读统计。制作当日 web 检索后端欠费无法在线抓取
> ReadPaper 官网核验最新版本，功能清单基于既有认知整理，正式 PRD 阶段需再核验一次。

## 页面清单

| 页面 | 文件 | 演示重点 |
|---|---|---|
| 发现首页 | `index.html` | 搜索（含热门词）、推荐卡片（**分页 3/页**）、本周热榜（**分页 5/页，排名全局连续**）、导入入口 |
| 知识图谱 ★新增 | `graph.html` | Canvas 力导向图（拖拽/缩放/重排），论文+概念节点、引用方向边、中心论文 BFS 展开、**知识点搜索→论文推荐**（概念/标签命中、直接/间接关联、排序、图谱定位/阅读/入库）、节点详情侧栏、过滤 |
| 社区交流 | community.html | **社区 Tab**：💬 动态流（公开笔记/总结+点赞评论+论文聚合）、👥 团队（创建/申请/审批/详情）、📤 分享管理（我分享的/分享给我的） |
| 知识库 | `vault.html` | 知识资产统计、**已读 AI 知识卡片（分页 6/页）**、跨论文术语库（分页）、笔记聚合（分页）、导出 Obsidian Markdown（frontmatter+双链） |
| 文献库 | `library.html` | **四 Tab 闭环**：📚 我的文献（⭐收藏/📁分类/🗑**移入回收站**，左侧🗑回收站可恢复/彻底删除）：📚 我的文献 → ⭐ 收藏网站 → **📖 阅读器（二级标签：📋 论文详情 \| 📖 原文，详情与阅读合一）** → **📥 导入文献（本地文件上传：单个/批量，每文件一张资料卡，字段与收藏网站导入一致：类别/状态/标签/简介+AI生成，支持单篇/批量导入）**；`?p=ID` 全局定位；右上角无导入按钮 |
| 网页导入（已并入文献库） | `browse.html` | 保留兼容入口，顶部提示跳转文献库「收藏网站」Tab；全部页面统一显示**一句话简介标签** |
| 论文详情 | `detail.html` | 三视图（详情/原文对照/翻译），**仅从阅读器顶栏进入**（文献库面板已合并为"📖 阅读论文"直达阅读器） |
| **阅读器** ★ | `reader.html` | 三栏布局：大纲 / 正文 / AI+笔记面板；正文三模式（原文/中英对照/**左右双栏+段落联动高亮+滚动同步**/全译文）、划词翻译/5色高亮/笔记/AI问答、进度条、引擎徽章 |
| 个人中心 | `profile.html` | 含 **💾 数据备份（导出/导入 JSON，防丢失/换环境迁移）**； 从**右上角头像菜单**进入（顶栏无"我的"Tab）：个人资料+修改资料弹窗、统计卡片、最近阅读、笔记汇总、收藏、个性化建议、**⚙ 偏好设置（翻译/OCR 引擎配置，原设置中心并入本页）**、退出登录 |
| 偏好设置（并入个人中心） | `settings.html`（无入口） | 翻译/OCR 引擎配置已并入 profile.html「⚙ 偏好设置」区块；settings.html 保留文件无入口 |

## 演示路径（建议顺序）

1. `index.html` → 点任意论文卡片 → `detail.html`（看 AI 总结动画）
2. 详情页点「开始阅读」→ `reader.html`
3. **阅读器重点交互**：
   - 顶部工具栏切换「原文 / 中英对照 / 全译文」（或 Ctrl+1/2/3）
   - **划词** → 浮动条出现：翻译（术语词典命中）/ 高亮（5 色）/ 笔记 / 问AI
   - 右侧「AI 对话」：点预设问题 chips 或自由提问（模拟流式回答）
   - 右侧「笔记」：查看/点击定位/删除高亮；刷新页面后笔记仍在（localStorage）
   - 滚动正文：顶部进度条 + 左侧大纲联动高亮
4. `library.html` → 文件夹/筛选/排序 → `profile.html` 看统计

## 数据说明

- 演示数据为 **7 篇真实论文**（Attention Is All You Need、ResNet、ViT、DETR、PP-OCR、TrOCR、MASTER），
  贴合 OCR / CV 业务方向；元信息真实，**引用量为演示近似值**
- 阅读器正文为 Attention Is All You Need 公开原文节选 + 人工译文（真实内容，非占位）
- AI 回答为预置演示（内存数据，无真实推理）

## 与最终产品的差异

| 项 | 原型 | 真实产品 |
|---|---|---|
| 数据 | 内存模拟 + localStorage | MySQL + 文献元数据库（Crossref/arXiv API） |
| 检索 | 本地关键词过滤 | 全文检索 + 语义检索 + 引用网络 |
| AI 能力 | 预置回答/模拟流式 | 接入大模型（翻译、总结、问答、术语解释） |
| 翻译 | 演示术语词典 | 全文级 AI 翻译引擎 |
| 文献导入 | 模拟解析 | 真实 DOI/arXiv 解析 + PDF 文本抽取（pymupdf）+ 扫描件 OCR |
| 账号/权限 | 单用户 | 多用户、小组、分享 |
| 阅读器 | 文本流渲染 | 原生 PDF 渲染 + 标注层叠加 |

## 打开方式

（注意：本机 8000 端口被 Data Flow Agent 占用，可用 8010：`python -m http.server 8010`）
